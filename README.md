# Kress Cooper Academy — Business Operating System Mockups

**For client presentation / sales conversion**

## How to open

1. Open `index.html` in any modern browser (Chrome, Edge, Safari, Firefox).
2. Click **Open Platform** or **Launch Interactive Demo** to enter the full app prototype.
3. Use the left sidebar to switch between:
   - Dashboard
   - Lead Board
   - Sales Board
   - KYC Board
   - Operation Board
   - Settings & Admin

No server or login required. Everything runs locally in the browser.

## Live preview

You can also open the raw files via GitHub Pages once enabled, or simply download and open locally.
